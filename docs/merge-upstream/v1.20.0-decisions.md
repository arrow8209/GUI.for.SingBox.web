## 关键决策

### 1. WebSocket 生命周期重构（pre-scan 警告项）

上游 v1.20 改 WebSocket 模式：把所有 WebSocket 实现从 `stores/kernelApi.ts` 搬到 `api/kernel.ts`，引入 per-channel `wsChannels` 通道结构 + `initWebsocket/destroyWebsocket` 全局函数。

**决策**：
- 采纳上游 wsChannels 模式 + initWebsocket/destroyWebsocket
- 但 base 必须走本地 Core Proxy（main.go handleCoreProxy 已支持 WS upgrade）
- `setupKernelApi/setupKernelWs` 拆分：HTTP 走 `X-Core-Base/X-Core-Bearer` headers，WS 走 query `coreBase/coreBearer/token`
- `stores/kernelApi.ts` 删除内部 WebSocket dead code（initCoreWebsockets/destroyCoreWebsockets/createCoreWSHandlerRegister/createCoreWSDispatcher/onLogsEvents/longLivedWS/shortLivedWS/websocketHandlers/websocketInstance/resolveCoreProxyWSBase）

### 2. Frontend reorganize（pre-scan 警告项）

上游 `b298a2f refactor(frontend): reorganize common components and views` 把 SplashView/AboutView/CommandView/TitleBar/NavigationBar 全搬到 `frontend/src/components/_common/`。

**决策**：
- 采纳上游目录重组（已自动合并）
- App.vue 改用 `import { SplashView, AboutView, CommandView } from '@/components'`（集中导出）

### 3. logo.png 资源缺失

上游 SplashView/TitleBar 直接 `<img src="@/assets/logo.png">`，本地只有 `logo.ts`（base64）。

**决策**：从 `build/appicon.png` 拷贝为 `frontend/src/assets/logo.png`（同图）

### 4. lang/index.ts API 重命名

上游 v1.20 把 `loadLocale` 重命名为 `loadLocaleMessages` + `reloadLocale`。

**决策**：保本地 `loadLocale`，加 export 别名 `loadLocaleMessages = loadLocale`、`reloadLocale = () => loadLocale()`

### 5. tsconfig node22 → node24

上游升级到 `@tsconfig/node24`，本地 package.json 已自动合并接受新版本。`pnpm install` 拉新依赖即可。

### 6. EnvData 加 `isPrivileged`（v1.19 已处理，本版自动合并）

继承 v1.19 的处理：bridge/app.ts EnvResult 类型 `isPrivileged?: boolean`，stores/env.ts setupEnv 默认 false。

### 7. file.name TS 严格化

上游 ReadDir 返回的 `file.name` 类型变为 `string | undefined`。本地 `stores/app.ts` 直接 `file.name.split('.')` 报错。

**决策**：改为 `(file.name || '').split('.')`

### 8. 5 个 modify/delete (②)

- `bridge/bridge.go`、`bridge/tray.go`、`frontend/src/bridge/wailsjs/**`：`git rm -f` 删除

### 9. main.go 残段

- 上游残留 Wails 入口（CreateTray + wails.Run + options.App 等大段 80 行）
- **决策**：用 python 移除，保留本地 `AuthConfig` struct

### 10. go.mod / go.sum
