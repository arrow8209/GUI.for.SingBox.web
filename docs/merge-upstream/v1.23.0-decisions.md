- 本地 GetEnv 只支持无参调用
- **决策**：改本地 GetEnv 支持可选 key：`<T extends string | undefined>(key?: T)` 返回 `string | EnvResult`

- **决策**：加 `os: _env.os as OS` 强制 cast
